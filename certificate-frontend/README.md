# Certificate Service

Full Stack Project using:
- Spring Boot
- PostgreSQL
- React JS
- pgAdmin

## Features
- Certificate Management
- Expiry Tracking
- Admin Dashboard

## Backend
Spring Boot REST API

## Frontend
Responsive UI using React JS

## Database
PostgreSQL

## Available Scripts

### `npm start`
Runs the application in development mode.

### `npm run build`
Builds the project for production.

### `npm test`
Runs test cases.
